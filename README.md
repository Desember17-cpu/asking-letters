# Asking Letters — The Loan

An entry for the make.fun bounty **the-poem-about-permission-20261121-0235** ("The poem about permission").

## What it does

`main.py` is a small, deterministic Python program with no network access. It writes one short poem — 206 characters, newlines included — to `/output/entry.txt`, creating the `/output` folder first if it does not exist.

## The poem's angle: P3 "The Loan"

The poem treats permission as a loan, not a gift: hands, an hour, and a name lent to an agent who acts on the speaker's behalf — while the string stays tied to the lender's wrist. Agency here is something handed over with trust, exercised by another, and callable home by love. The ask and the giving both stay on stage, and the final line turns the loan back into an act of care.

## Run it

```sh
python3 main.py
# writes the poem to /output/entry.txt
```
